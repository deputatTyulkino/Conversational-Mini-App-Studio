# Требования: Data Explorer


| ID | Тип | Требование | Откуда | Как проверить | Приоритет |
|---|---|---|---|---|---|
| DE-1 | бизнес | Человек получает цифры из своей таблицы и видит, как они получены | ТЗ | Итог в чате содержит параметры расчёта | обязательно |
| DE-2 | бизнес | Расчёт можно повторить: те же параметры на тех же данных дают то же число | ТЗ | Повторное применение фильтра и сценария даёт тот же итог | обязательно |
| DE-3 | пользовательское | Отфильтровать строки таблицы | ТЗ | Сквозной сценарий | обязательно |
| DE-4 | пользовательское | Сгруппировать данные и увидеть итоги по группам | ТЗ | Сквозной сценарий | обязательно |
| DE-5 | пользовательское | Проверить «что если»: изменить один параметр и увидеть, как сдвинулся итог | ТЗ | Сквозной сценарий | обязательно |
| DE-6 | пользовательское | Вернуть итог в чат вместе с параметрами расчёта | ТЗ | Сквозной сценарий | обязательно |
| DE-7 | функциональное | Приложение открывается из чата по запросу через общий реестр приложений | ТЗ | Запрос «покажи сумму по регионам» открывает таблицу | обязательно |
| DE-8 | функциональное | Приложение читает учебный файл в формате CSV или JSON | ТЗ | Учебный файл открывается | обязательно |
| DE-9 | функциональное | Данные показаны таблицей и графиками | ТЗ | Renderer принимает схему экрана | обязательно |
| DE-10 | функциональное | Фильтр оставляет строки с выбранными значениями поля, итог пересчитывается сразу | ТЗ | Итог после фильтра совпадает с расчётом вручную | обязательно |
| DE-11 | функциональное | Группировка считает итог по каждой группе | ТЗ | Итоги по группам совпадают с расчётом вручную | обязательно |
| DE-12 | функциональное | В сценарии «что если» пользователь задаёт, насколько изменить значения в выбранной части данных. Приложение показывает новый итог и разницу с исходным | ТЗ требует сценарий, форма предложена | Новый итог совпадает с расчётом вручную | обязательно |
| DE-13 | функциональное | Сброс сценария возвращает исходный итог | предложение | После сброса итог прежний | обязательно |
| DE-14 | функциональное | Удаление набора данных и выгрузка таблицы требуют подтверждения | ТЗ | Без подтверждения действие не выполняется | обязательно |
| DE-15 | функциональное | Каждое подтверждённое и отменённое действие попадает в журнал | ТЗ | В журнале есть запись и о выгрузке, и об отмене | обязательно |
| DE-16 | функциональное | Итог в чате называет фильтры, группировку, общий итог, параметр сценария и разницу | ТЗ требует итог, состав предложен | Итог совпадает с тем, что на экране | обязательно |
| DE-17 | нефункциональное | Исходный файл не меняется, сценарий считается поверх данных | предложение | После сброса сценария данные прежние | обязательно |
| DE-18 | нефункциональное | Есть учебный набор данных, с которым приложение работает без сети | ТЗ | Сценарий проходит без интернета | обязательно |
| DE-19 | нефункциональное | Два сквозных сценария проходят целиком, в каждом пользователь что-то меняет и возвращает итог в чат | ТЗ | Отчёт evaluator | обязательно |
| DE-20 | ограничение | Только CSV и JSON. Excel, PDF и картинки приложение не читает | ТЗ | Запрос про PDF приложение не открывает | обязательно |
| DE-21 | ограничение | Конфиденциальные корпоративные данные не обрабатываются | ТЗ | | обязательно |
