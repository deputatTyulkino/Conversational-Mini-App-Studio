# Требования: Research Board


| ID | Тип | Требование | Откуда | Как проверить | Приоритет |
|---|---|---|---|---|---|
| RB-1 | бизнес | До сдачи работы автор видит, какие утверждения ему нечем подтвердить | ТЗ | На учебной доске приложение находит утверждение без источника | обязательно |
| RB-2 | бизнес | Связь между утверждением и источником записана, её можно показать проверяющему | ТЗ | Связи видны на доске и попадают в итог, который уходит в чат | обязательно |
| RB-3 | пользовательское | Добавить на доску утверждение и источник | предложение | Сквозной сценарий | обязательно |
| RB-4 | пользовательское | Связать утверждение с источником и снять связь | ТЗ | Сквозной сценарий | обязательно |
| RB-5 | пользовательское | Увидеть все утверждения без источника одним списком | ТЗ | Сквозной сценарий | обязательно |
| RB-6 | пользовательское | Отметить, что источник противоречит утверждению, и увидеть такие пары | ТЗ, описание доски | Отмеченная пара выделена на доске | желательно |
| RB-7 | пользовательское | Вернуть итог работы с доской в чат | ТЗ | Сквозной сценарий | обязательно |
| RB-8 | функциональное | Доска открывается из чата по запросу через общий реестр приложений, отдельной страницы у неё нет | ТЗ | Запрос «какие утверждения в докладе ничем не подкреплены» открывает доску | обязательно |
| RB-9 | функциональное | Утверждение считается неподтверждённым, если у него нет ни одной связи с источником | предложение | Тест на учебной доске | обязательно |
| RB-10 | функциональное | После каждого изменения список неподтверждённых утверждений пересчитывается | предложение | После привязки источника утверждение уходит из списка | обязательно |
| RB-11 | функциональное | Удаление утверждения или источника требует подтверждения | ТЗ | Без подтверждения доска не меняется | обязательно |
| RB-12 | функциональное | Перед удалением источника приложение называет утверждения, которые останутся без опоры | предложение | Названия есть в тексте подтверждения | желательно |
| RB-13 | функциональное | Массовое удаление и выгрузка доски требуют подтверждения | ТЗ | Без подтверждения действие не выполняется | обязательно |
| RB-14 | функциональное | Каждое подтверждённое и отменённое действие попадает в журнал | ТЗ | В журнале есть запись и об удалении, и об отмене | обязательно |
| RB-15 | функциональное | Итог в чате называет число утверждений, источников и связей и перечисляет утверждения без источника | ТЗ требует итог, состав предложен | Итог совпадает с тем, что на доске | обязательно |
| RB-16 | функциональное | Экран собран из общих примитивов платформы: карточка, таблица, форма, ссылка на источник | ТЗ | Renderer принимает схему экрана | обязательно |
| RB-17 | нефункциональное | Есть учебный набор данных, с которым доска работает без сети | ТЗ | Сценарий проходит без интернета | обязательно |
| RB-18 | нефункциональное | Два сквозных сценария проходят целиком, в каждом пользователь что-то меняет и возвращает итог в чат | ТЗ | Отчёт evaluator | обязательно |
| RB-19 | нефункциональное | Ссылки на источники открываются только по http и https | предложение | Ссылка другого вида отклоняется | желательно |
| RB-20 | ограничение | Источники в интернете приложение не ищет | ТЗ | Запрос «найди статьи» доску не открывает | обязательно |
| RB-21 | ограничение | Связи ставит человек. Приложение не читает тексты источников и не подбирает подтверждения само | ТЗ | | обязательно |
| RB-22 | ограничение | Конфиденциальные корпоративные документы не обрабатываются | ТЗ | | обязательно |
